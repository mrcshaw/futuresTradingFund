Indicator Researcher
The next setting follows the last result. A change that lowers profit is reversed. A change that raises profit is continued. When those knobs stall, a filter such as VWMA, EMA, or RSI is added. The best version uses be_trigger_dollars=200.0, cooldown_bars=0, pv=50.0, sess_end_hr=8, sess_end_mn=0, sess_start_hr=18, sess_start_mn=0, stop_dollars=200.0. Attempts recorded: 200.

1. The bet
This version tries to catch a breakout. It can trade long and short. The coded conditions that build the entry signal must all be true, including any session filter and cooldown on this version. The fill is at the signal bar's close.

2. The stop that is actually active
This version uses a fixed dollar stop. Initial risk is 4 points, $200. The coded reward is $400. The reward-to-risk ratio is 2.00. The win rate required before commission and slippage is about 33.3 percent. If the file codes more than one stop, the figures above are the inputs on the version the engine kept.

3. The target
Take profit on this version: $400. Winners are capped at that take profit. This version does not describe a split. The position exits together when the target, the stop, or a session flat is hit.

4. The trailing stop and breakeven
The trailing stop is off in this version, and breakeven is off. The backtest of this version says nothing about a strategy trail. A trail that is not in the code cannot lock profit, cut winners, or replace a profit cap. The account rule is separate. The $2,000 trailing drawdown must not be crossed before the $3,000 profit target is met.

5. Time of day
The coded session is 18:00 to 08:00 Eastern Time. 9:30 is stood aside. The first hour is stood aside. Midday is stood aside. The cash close, 15:00–16:00, is stood aside. The 18:00 reopen is traded with the same rules. Positions are forced flat when the session ends. Where 9:30 uses the same rules as the rest of the day, that is stated above. The open is the least reliable part of a backtest when orders fill on the bar close and stops are not checked every tick, because one bar can hit both the stop and the target.

6. Costs and size that change the result
Point value is $50 per point. Contracts are 1. Commission is $5.5 a side. Slippage is 1. Pyramiding is 0. Cooldown after an exit is whatever cooldown input the file names; if it has none, the script does not wait. Round-trip commission is $11. Slippage is coded as 1 tick, taken as $12.5 at a 0.25 point tick. That is 0.47 points, which is the cost to set next to the stop and the target.

7. What the backtest cannot prove
Orders in this version fill on the close. Stops are not calculated every tick. No declared input was found unused in the entry. A level that needs future bars is not a live signal.

8. Where this kind of rule set usually makes and loses money
Winners are capped, so a large trend pays only the target. Losers take the full coded stop when a stop is hit. Trades still open at the session end are cut by the session flat. The open is outside the coded session, so the open itself is stood aside. Settled for the best version: profit 123.5, drawdown 6010.0, trades 174, trail cleared: no.
