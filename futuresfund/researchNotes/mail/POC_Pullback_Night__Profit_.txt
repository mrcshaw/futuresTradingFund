Indicator Researcher
The next setting follows the last result. A change that lowers profit is reversed. A change that raises profit is continued. When those knobs stall, a filter such as VWMA, EMA, or RSI is added. The best version uses lookback=51, rows=12, stop=214. Attempts recorded: 200.

1. The bet
This version tries to catch a breakout. It can trade long and short. The coded conditions that build the entry signal must all be true, including any session filter and cooldown on this version. The fill is intrabar, because calc_on_every_tick is on.

2. The stop that is actually active
This version uses a forced session exit, with no separate dollar stop named. Initial risk is not stated as a point distance. No fixed reward is coded beside the stop. The reward-to-risk ratio is not defined. The win rate required before commission and slippage is about not defined from a fixed stop and target. If the file codes more than one stop, the figures above are the inputs on the version the engine kept.

3. The target
Take profit on this version: no fixed take profit is set. A trail is coded, so a winner can stay open until that trail or a session flat takes it. The position is not described as split.

4. The trailing stop and breakeven
The trailing stop is on in this version. Breakeven is off. The file does not state a separate arming price beyond the trail input it contains. Updates are every tick. A trail that is on sits under any fixed target the file also codes, and it can only be judged from that code, not from a version where the trail was switched off. Design judgment: where a trail is on, it locks profit only after price has moved in favor of the trade, and it can cut a winner before a fixed cap if both are present. The account rule is separate. The $2,000 trailing drawdown must not be crossed before the $3,000 profit target is met.

5. Time of day
The coded session is 18:00 to 08:00 Eastern Time. 9:30 is stood aside. The first hour is stood aside. Midday is stood aside. The cash close, 15:00–16:00, is stood aside. The 18:00 reopen is traded with the same rules. Positions are forced flat when the session ends. Where 9:30 uses the same rules as the rest of the day, that is stated above. The open is the least reliable part of a backtest when orders fill on the bar close and stops are not checked every tick, because one bar can hit both the stop and the target.

6. Costs and size that change the result
Point value is $50 per point. Contracts are 1. Commission is $5.5 a side. Slippage is 1. Pyramiding is 0. Cooldown after an exit is whatever cooldown input the file names; if it has none, the script does not wait. Round-trip commission is $11. Slippage is coded as 1 tick, taken as $12.5 at a 0.25 point tick. That is 0.47 points, which is the cost to set next to the stop and the target.

7. What the backtest cannot prove
The script does not set fills on the close. calc_on_every_tick is on. No declared input was found unused in the entry. A level that needs future bars is not a live signal.

8. Where this kind of rule set usually makes and loses money
Winners are not capped by a fixed target in the file. Losers take the full coded stop when a stop is hit. Trades still open at the session end are cut by the session flat. The open is outside the coded session, so the open itself is stood aside. Settled for the best version: profit 10528.0, drawdown 1964.0, trades 47, trail cleared: yes.
