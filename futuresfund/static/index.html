Under the hood

Three engines per instrument

Every instrument has its own 2-minute, 5-minute and 15-minute engine, one row each: engines 1-3 are ES, 5-7 GC, 8-10 NQ, 11-13 MNQ, 14-16 MES, 17-19 M2K and 20-22 YM. Engine 4 is the creation engine. An engine studies only its own instrument's chart, so two instruments can test the same script at once. The engines run their backtests on a shared pool of PineTS worker processes; an engine that shows "Waiting for a free worker" is next in line. The scale goal is the acceptance number chosen on the strategy library page. The table is the last 20 results on that engine. Click a result to open the script and settings that run used. Restart stops a hung engine and takes the next learning script. Skip leaves the current script and takes the next one.

What the traders execute

Start hands a card's Pine script to a trader. The first strategy started is the floor trader's and the second is the quantitative trader's. Two can run at once. Both run on the desk chart. The quantitative trader books those fills on paper and does not send an order. A position the script is still in is taken at the latest price. Every open trade is closed before 4:45pm ET. A trade the script already closed before Start is not replayed.

Strategy library

Most profitable runs

A run is filed when it has passed the 7, 30, and 90-day tests, the year meets the checked boxes, and its profit grows from each window to the next longer one. Each test needs the profit and trade boxes pro-rated to its share of a 260-session year, 5, 21, and 64 sessions: the table under the boxes shows the numbers. The drawdown rule, the stop, the profit factor, and the win rate are the same on every test. Every test and the year allow at most 600 trades a year at the run's pace, and the year must also make more than its drawdown. The drawdown box is the pro account rule: each dip may reach $2,500 on a $50,000 account until the profit passes the $3,000 target, then $2,500 plus 30 percent of the profit above $3,000. The stop may never be set above 1.5 percent of the account, $750 on $50,000. A fill past a stop set there is the market, and the strategy still counts. The drawdown box and the trade count start checked. Check another box to require that number too. One version of each name stays on each contract and timeframe. A one-year research run stays in the list below until the longer test.

Not tested on the full dataset

Research measures the last year. A run that clears the acceptance numbers above stays here until the five-year test. A run with its stop set above 1.5 percent of the account does not stay. A run with more than 900 trades, or more than 600 trades a year, is never filed. The desk does not refuse a script like that: the chart researcher cuts its trades with daily loss and profit limits, a longer cooldown and most trades a day, and asks you when 12 cuts in a row are still over. It is not added to the most profitable runs until that full dataset is profitable. A hand-added script stays here too.

Proving stages

7, 30, 90 and 365 day backtests

Each script is backtested on the last 7 days first, then 30, then 90, then the full year. Each test has its own number of attempts, set on the Research workflow page (100 for 7 days, 150 for 30, 200 for 90 and 300 for the year in the code). A pass does not end a test: it keeps searching for more profit with less drawdown, and stops when its attempts are spent or 25 attempts in a row found no better pass. The next test starts from the best pass, and a test with no pass ends the study there. Each row is one script on one contract and timeframe, and the table keeps the latest 100 rows. A window it passed shows its best pass's profit and the attempts that test used. Click a passed stage to open the script with the inputs of that best pass, and copy it.
